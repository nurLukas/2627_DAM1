nurLukas - Namespace Persona

Este URI identifica el espacio de nombres XML utilizado para representar personas en documentos XML de nurLukas.

URI del espacio de nombres

https://nurLukas.com/persona

Elementos

  • persona - Representa una persona.
  • nombre - Nombre de la persona.
  • apellidos - Apellidos de la persona.
  • email - Dirección de correo electrónico.

Ejemplo

<?xml version="1.0" encoding="UTF-8"?>

<nurLukas:persona
    xmlns:nurLukas="https://nurLukas.com/persona">

    <nurLukas:nombre>Lucas Ezequiel</nurLukas:nombre>
    <nurLukas:apellidos>Andrés Griego</nurLukas:apellidos>
    <nurLukas:email>admin@sturmprojekt.es</nurLukas:email>

</nurLukas:persona>
